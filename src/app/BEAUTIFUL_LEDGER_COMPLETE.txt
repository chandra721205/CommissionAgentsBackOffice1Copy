║                      SECURITY FEATURES                               ║
╚══════════════════════════════════════════════════════════════════════╝

🔐 OTP VERIFICATION
   ├─ Grant advance → Store last 4 digits in otp_grant_last4
   ├─ Close/repay → Store last 4 digits in otp_close_last4
   └─ Complete audit trail

👥 MULTI-ROLE PERMISSIONS
   ├─ Weighing laborer → Can only record weights
   ├─ Market salesman → Can view sales only
   ├─ Commission agent → Full access
   └─ Scope by villages & operations

🛡️ IMMUTABILITY
   ├─ Append-only ledger entries
   ├─ No deletion, only soft delete
   ├─ Complete audit trail
   └─ Blockchain-ready
