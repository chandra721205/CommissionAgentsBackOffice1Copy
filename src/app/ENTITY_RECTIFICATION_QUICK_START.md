## 🔍 Troubleshooting

### Issue: Can't Find Enhanced Version
**Solution**: Look for card with purple "✨ ENHANCED" badge at welcome screen. Scroll down if needed.

### Issue: Blockchain QR Not Opening
**Solution**: Click directly on the entity ID badge (looks like a chip with lock icon).

### Issue: Voice Input Not Working
**Solution**: 
1. Check browser permissions (allow microphone)
2. Use Chrome/Edge (best compatibility)
3. Look for mic icon inside text fields

### Issue: Languages Not Switching
**Solution**: 
1. Look for globe icon buttons (top-right)
2. Click EN/HI/TE buttons
3. UI should change immediately

### Issue: OTP Rings Not Animating
**Solution**: 
1. Complete Step 1 first (enter change details)
2. Click "Proceed to OTP Verification"
3. Rings appear in Step 2

### Issue: Data Not Masking in Public View
**Solution**: 
1. Ensure you clicked rightmost button (Eye-Off icon)
2. Button should have dark background when active
3. Data changes to ••••••••

## 🎓 Understanding the 7 Screens

### Current Implementation
The 7 screens are integrated into a single scrollable dashboard:

**Screen 1**: Entity Overview Panel (Top)
**Screen 2**: Change Management Tracker (Below overview)
**Screen 3**: Permissions & Control Matrix (Below tracker)
**Screen 4**: OTP Authorization Modal (Popup when requesting change)
**Screen 5**: KYC Re-Verification (Conditional - appears after 3 changes)
**Screen 6**: Audit & Logs Section (Below matrix)
**Screen 7**: Confidentiality Toggle (Top-right view mode buttons)

**Navigation**: Scroll to see screens 1-3, 6. Modals (4-5) appear on interaction. Toggle (7) always visible.

## 💡 Pro Tips

### Tip 1: Test OTP Flow Multiple Times
The OTP modal can be triggered multiple times. Just close and reopen to test again.

### Tip 2: Language Switching is Instant
No page reload needed. Try switching between EN/HI/TE rapidly to see smooth transitions.

### Tip 3: View Modes Affect All Sections
Public view masks data across all sections (overview, matrix, logs). Toggle back to see changes.

### Tip 4: Grok AI Insights Are Contextual
Different insights appear based on:
- Entity type (MSME gets fast-track mention)
- View mode (GDPR insight only in Public view)
- Screen location (each section has specific insight)

### Tip 5: Animations Can Be Slowed Down
To better see animations:
1. Open DevTools
2. Go to Settings → Preferences
3. Set Animations to "slow"
